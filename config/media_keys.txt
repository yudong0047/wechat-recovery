# 加密算法: AES-256-CBC
# page_size: 4096

# .dat 文件加密格式
# V2 格式: header = 07 08 V2 08 07 + AES-128-CBC + XOR 0xe1
# 变种1 (JPEG): XOR 0xe1 → FF D8 FF (0x1E 0x39 0x1E 加密态)
# 变种2 (PNG):  XOR 0xe1 → 89 50 4E 47 (0x68 0xB1 0xAF 0xA6 加密态)

# 关键发现
# 1. 微信打开 .dat 会自动 XOR 0xe1
# 2. 如果 .dat 是明文 JPG/PNG → 微信 XOR 后变垃圾 → 显示不出来!
# 3. 必须先 XOR 一次加密回去 (1E 39 1E / 68 B1 AF A6) → 微信才能解
# 4. 清缓存后微信会重新扫描所有 .dat 生成缩略图
